# Example 18: Computer Vision - Pose Estimation

**Date:** 2026-02-22
**Status:** Approved

## Overview

Add Example 18 to ai101: real-time pose estimation with skeleton overlay using a webcam. This is the first example that requires external Python packages (OpenCV + ultralytics). It introduces students to computer vision - how AI can "see" and understand human body position in real-time.

The example runs on both GPU/CPU (via ultralytics) and on the Orange Pi 5 Plus NPU (via CIX NOE_Engine). A Go version uses GoCV with ONNX model inference.

The accompanying exercises build a progressive journey from basic color detection to full skeleton analysis, with printable PDF materials for hands-on experimentation.

## Approach

**Approach A: Single monolithic file per language.** Each example is one self-contained file following the existing ai101 pattern. NPU variant is a separate file (like `01_basic_chat_OPENAI.py` is a variant of `01_basic_chat.py`).

## Python example structure

Following ai101 pattern: single file, ~200 lines, 80% comments/documentation.

```
Header docstring:
  WHAT THIS DEMONSTRATES: Real-time computer vision with AI pose estimation
  WHAT YOU'LL LEARN: Camera capture, frame processing, keypoint detection, skeleton drawing
  PREREQUISITES: pip install ultralytics opencv-python
  EXPECTED OUTPUT: Live camera window with 17-point skeleton overlay

Step 1: Import libraries (cv2, ultralytics)
Step 2: Load the YOLOv8s-pose model (explain: trained neural network, 6MB, 17 keypoints)
Step 3: Open the camera (explain: video capture, frames, FPS)
Step 4: The main loop (~15 lines of actual code)
  - Read one frame
  - Run pose estimation
  - Draw skeleton (17 keypoints + connections)
  - Show frame in cv2 window
  - Wait for 'q' key
Step 5: Cleanup

Reference section:
  - COCO 17 keypoints list
  - Skeleton connections
  - Confidence scores
  - FPS calculation
```

## Exercise progression

### Exercise 18.1: Blue Ball Detection
- **Concept:** HSV color space (Hue = color on the wheel, Saturation = intensity, Value = brightness)
- **Task:** Detect a blue object in camera feed, draw bounding circle
- **Materials:** Any blue ball or blue object
- **Code snippet provided:** Convert BGR to HSV, create mask for blue range, find contours, draw circle
- **Observation:** How lighting affects detection, try different colors by changing HSV range

### Exercise 18.2: Shape Detection
- **Concept:** Edge detection (Canny), contour approximation (approxPolyDP)
- **Printable:** `18_shapes.pdf` generated by `18_generate_shapes_pdf.py`
- **Shapes:** Circle, triangle, square, rectangle, pentagon, hexagon, star, arrow
- **Task:** Hold cutout shapes in front of camera, detect and classify by vertex count
- **Code snippet:** Grayscale, Canny edges, find contours, approximate polygon, classify
- **Observation:** 3 vertices = triangle, 4 = rectangle, many = circle

### Exercise 18.3: ArUco Marker Detection
- **Concept:** Fiducial markers, camera-to-world mapping, unique IDs
- **Printable:** Generated by `python exercises/18_generate_aruco_pdf.py`
- **Task:** Detect markers, overlay IDs, measure distance between markers
- **Code snippet:** `cv2.aruco.detectMarkers()`, draw, print IDs
- **Extension:** Tape to walls, estimate distance using known marker size
- **Observation:** Works from any angle, even partially occluded

### Exercise 18.4: Face Detection with Haar Cascades
- **Concept:** Classical CV (pre-deep-learning), sliding window, feature cascades
- **Task:** Detect faces using OpenCV built-in cascade (no model download)
- **Code snippet:** `cv2.CascadeClassifier`, `detectMultiScale`, draw rectangles
- **Observation:** Compare speed vs accuracy with YOLO. Fails on side profiles, masks, low light.

### Exercise 18.5: Skeleton Analysis
- **Concept:** Angles between keypoints, body measurement
- **Task:** Measure knee angle in real-time from skeleton keypoints
- **Code snippet:** Extract hip/knee/ankle keypoints, compute angle with atan2, display
- **Extension:** Count squats (knee angle below 90 degrees and back up)
- **Observation:** Confidence drops when body parts are occluded

### Exercise 18.6: Build Your Own - Mini Jump Analyzer
- **Capstone:** Combine everything learned
- **Task:** Track hip Y over time, detect jumps, measure air time
- **Hints provided, no full solution**
- **Reference:** The `jump` project does this at production scale

## PDF generators

### `18_generate_aruco_pdf.py` (~50 lines)
- Uses `cv2.aruco` to generate 4x4_50 dictionary markers
- Grid of 12 markers (4 rows x 3 columns) with ID labels
- Outputs PDF via matplotlib
- Students can modify marker count, size, dictionary

### `18_generate_shapes_pdf.py` (~60 lines)
- Draws geometric shapes on white page using OpenCV drawing
- 8 shapes: circle, triangle, square, rectangle, pentagon, hexagon, star, arrow
- Each labeled, ~5cm, with dashed cut lines
- Outputs PDF
- Students can modify sizes, add shapes
